# WGIYV! [![](https://cf.way2muchnoise.eu/short_323269.svg)](https://www.curseforge.com/minecraft/mc-mods/wgiyv)
WGIYV (which stands for "We Get It You Vape") is a 
Minecraft mod that adds a simple mod and tank 
for you to vape upon in Minecraft. Go hipster!  
  
  
_This mod requires [CTD Core](https://www.curseforge.com/minecraft/mc-mods/ctd-core)!_
